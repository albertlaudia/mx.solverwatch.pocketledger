# media/brand/

Master brand assets. Source files (Figma exports, font files, design tokens) live here. The Flutter app reads the same tokens via `packages/ui/lib/src/tokens/`.

**Contents** (when populated):
- `logo/` — primary logo, inverse logo, mark (icon source)
- `wordmark/` — horizontal wordmark for headers/footers
- `colors/` — design tokens (mirrors `packages/ui/lib/src/tokens/`)
- `fonts/` — Inter Regular / Medium / SemiBold (TTF, OFL licensed)

See `/media/README.md` for the full spec.
