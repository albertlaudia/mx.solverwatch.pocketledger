# media/app-store/

All assets for the Apple App Store submission. See `/media/README.md` for the full iOS spec.

**Subfolders**:
- `icon/` — 1024×1024 PNG (no alpha, sRGB) → `app-icon-1024.png`
- `screenshots/` — 5 device classes (iPhone 6.7", 6.5", 5.5"; iPad 12.9"), up to 10 per class
- `metadata/` — App Store Connect text fields (description, subtitle, keywords, URLs)
- `store-listing-screenshots/` — the 10 promo screenshots in 1290×2796 (the "marketing" set)

**Submission** (Epic 9):
- App Store Connect → App Information + Pricing and Availability
- Versions → iOS App → 1024×1024 icon + screenshots per device class
- App Privacy → "Data Not Collected" answers
- App Review → demo account (no account needed; reviewer uses onboarding flow)
